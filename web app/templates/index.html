📌 Fungsi Aplikasi

Aplikasi ini digunakan untuk mengecek keamanan sebuah link (URL) menggunakan integrasi API Virustotal dan indikator keamanan.

Sistem akan mencari pola yang sering ditemukan pada:

  • Phishing
  • Scam
  • Malware
  • Link mencurigakan

Setelah dianalisis, sistem akan memberikan skor risiko untuk membantu menentukan apakah link aman dibuka atau perlu dihindari.

🛡️ Kategori Risiko
  • Sangat Aman
    Hampir tidak ada indikator mencurigakan.
  • Aman
    Relatif aman tetapi tetap berhati-hati.
  • Waspada
    Terdapat beberapa pola mencurigakan.
  • Cukup Berisiko
    Hindari memasukkan data pribadi.
  • Berbahaya
    Risiko phishing atau malware tinggi.
  • Sangat Berbahaya
    Risiko sangat tinggi, jangan dibuka.
